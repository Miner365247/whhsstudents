Getting started:
	Put your yearbook proofread PDF files into the "pdfs" folder. These files can be acquired from your school email.
	Run the setup script for your platform in the directory your pdf folder is.
	For Linux I suggest being in a virtual environment as pip is often disabled on system python
	For Windows, pip and python should be in your PATH, but you can edit the setup.bat file to use "py" or "py -m pip"
	Mac, you're on your own.
	Scripts:
		Windows: setup.bat
		Linux: setup-linux.bat
		Mac: setup-mac.bat
	Using app.py:
		You need PyGObject, libadwaita, and pyperclip installed to python.
		Windows you need to use msys2, and Mac use brew.
			For pyperclip on msys2, id recommend using the pyperclip source code in the same directory as app.py.
